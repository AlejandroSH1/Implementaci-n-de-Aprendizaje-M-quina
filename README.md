# Implementación de Aprendizaje Maquina

## Alfredo Alejandro Soto Herrera

En este Repositorio se encuentra lo relacionado al proyecto de la concentración "Inteligencia artificial avanzada para la ciencia de datos" de primer periodo.

Se encuentran los archivos:
- **model.py**: En este archivo python se encuentra toda la implementación del modelo sin utilizar un framework, permitiendo generar predicciones en base al dataset que se obtuvo.
- **Paper_AlejandroSoto.pdf**: Este archivo explica detalladamente todo lo realizado en este proyecto (EDA, ETL y Modelo), dejando en claro el por qué se tomaron las decisiones que se tomaron.
- **EDA y ETL.ipynb**: Jupyter notebook en el que se muestran todos los pasos realizados en el EDA y en el ETL para entender y visualizar los datos, además de modificarlos para su uso adecuado.
- **college_sleep_and_gpa.csv**: Dataset original extraído de Kaggle.
- **df_processed.csv**: Dataset después de haber hecho el EDA y ETL.
