# Implementación de Aprendizaje Maquina

## Alfredo Alejandro Soto Herrera

En este Repositorio se encuentra lo relacionado al proyecto de la concentración "Inteligencia artificial avanzada para la ciencia de datos" de primer periodo.

Se encuentran los archivos:
- **main.py**: En este archivo python se encuentra todo lo relacionado a lo hecho en el proyecto, desde el ETL, EDA y la implementación de un algoritmo de regresión para predecir nuevos valores.
- **Paper_AlejandroSoto.pdf**: Este archivo explica detalladamente todo lo realizado en este proyecto, dejando en claro el por qué se tomaron las decisiones que se tomaron.
